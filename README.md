# Heart Disease Prediction App 🩺

##Overview
This project is an end-to-end Machine Learning solution that predicts heart disease risk. It features a robust **ML Pipeline** and a user-friendly **Streamlit** web application.

## Key Features
* **Automated Pipeline:** Integrated data transformation and model prediction into a single pipeline for production readiness.
* **Streamlit Dashboard:** Created an interactive UI where users can input health metrics (Age, Cholesterol, BP, etc.) to get instant predictions.
* **Model Serialization:** Trained models are saved as `.pkl` files for efficient reloading.
* **Data Visualization:** Comprehensive EDA to understand feature importance.

## Tech Stack
* **Framework:** Streamlit
* **ML Libraries:** Scikit-Learn, Pandas, NumPy
* **Deployment:** Python-based Web Server
